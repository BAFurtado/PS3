# Moovit timetables, Entorno semiurban lines (collected by hand)

Moovit blocks scripted access, so each file here is a line's "Horários" page, copied from the browser.
File name: `<line>_<destination>.txt`, one per direction. Keep the stop/time table ("Estação  Partida #1 ...").
Parsed by tools/transport (Entorno layer, TBD). Moovit page footer gives the update date.
